# Moo's Profile — Plan Archive (consolidated)

One-file summary of all completed plans (originals deleted). Each entry: what was done and where it lives in the codebase.

## 02 / 04 — Pagination
- Server-side pagination added to `content_sdk` (git dep), client-side pagination wired into the Content page. Later superseded by the tag/two-column redesign (plan 08).

## 05 — Content Route → Feature Module
- Content page split out of routes into `src/features/content/` (content card, detail, grouped list, inline viewer, tag filter bar, hooks).

## 06 / 07 — Modal Component + Card Preview
- Reusable `Modal` (`src/components/modal.rs`, dark/light backdrop) showing a content-card preview before opening the full detail.

## 08 — Content Page Redesign
- Content page rebuilt as tag bar + two-column layout (topics list left, inline viewer right), replacing the paginated card grid.

## 09 — Content Own Layout
- Content routes render standalone (Nav only, no Header/Footer) via `use_route()` check in `ProfileLayout` (`src/routes/mod.rs`), since `#[layout]` always nests.

## 10 / 11 — Chat Route (LatCal)
- `/chat` page: messenger-style UI for the `latent-calculator` natural-language math bot; localStorage transcript persistence, auto-scroll, sync replies. `src/routes/chat.rs`.

## 12 / 13 / 14 / 15 — Google AdSense
- `Adsense` component (`src/components/adsense.rs`): lazy init via IntersectionObserver, wasm_bindgen inline JS push, feature-gated by `ads` cargo feature.
- Clean-code pass: env-driven config through `build.rs` (`ADSENSE_CLIENT_ID` parsed from `index.html`, `PLACEHOLDER_CLIENT_ID`, `PLACEHOLDER_AD_SLOT` overridable), documented in `.env.sample`.
- Renders nothing when feature off or IDs are placeholders.

## 16 / 17 / 18 — SEO Files
- `sitemap.xml` generated by `scripts/update-sitemap.mjs` (static routes + published slugs from Supabase; reads `.env`).
- `robots.txt`, `ads.txt` copied un-hashed into `dist/public`; routed before the SPA catch-all in `vercel.json`.
- Full production flow codified in the `Makefile`: `make build` = clean → sitemap → `dx bundle --release` → copy statics. (`make dev` / `make test` for dev.)
